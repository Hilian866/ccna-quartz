# Sito degli appunti CCNA 200-301

Sito statico costruito con [Quartz](https://quartz.jzhao.xyz/) (licenza MIT, vedi `LICENSE.txt`).

Le note non stanno in questo repository: la build le scarica da
[Hilian866/ccna-appunti](https://github.com/Hilian866/ccna-appunti) (vedi `.github/workflows/deploy.yml`).
La build parte a ogni push qui, ogni giorno alle 04:17 UTC e a mano dalla scheda Actions.

La configurazione del sito è in `quartz.config.ts` (titolo, lingua, percorsi esclusi).
